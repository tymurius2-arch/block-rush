# Block Rush

Залипательная головоломка: перетаскивай фигуры на поле 8×8, собирай полные ряды и столбцы. Комбо, рекорды, работает без интернета.

Играть: https://tymurius2-arch.github.io/block-rush/

На iPhone: открой в Safari → Поделиться → «На экран „Домой“». Открой один раз с иконки при интернете — дальше работает офлайн.
