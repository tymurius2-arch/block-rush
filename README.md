# 100 игр

Сборник из 100 игр для телефона, работает без интернета: аркады, спорт, головоломки, настольные игры против компьютера, тренировка мозга и игры для отдыха.

Играть: https://tymurius2-arch.github.io/block-rush/

На iPhone: открой в Safari → Поделиться → «На экран „Домой“». Открой один раз с иконки, пока есть интернет — потом всё работает офлайн.

Устройство: `engine.js` — меню и общий движок, `games1.js` … `games5.js` — сами игры (по 12–25 в файле), `sw.js` — офлайн-кэш.
